# Portfolio working rules

Before UI, interaction, public-copy, or design-review work, read:

- `docs/design/DESIGN_PRINCIPLES.md` (portable D01–D10 principles).
- `docs/design/DESIGN_SYSTEM.md` (this site's tokens and component contracts).

Reuse shared components/tokens. Keep copy faithful to approved sources and owner corrections; never invent evidence. Inspect the actual current desktop/mobile render and relevant interaction states, not just tests or old screenshots. Document justified exceptions rather than adding silent one-off styles.

Respect the requested task mode: audit-only sessions remain read-only; implementation self-checks are not independent verification. Preserve private assets, historical reports, publication controls and unrelated work. Do not deploy or enable indexing without explicit permission.
